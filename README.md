Programa para criptografia e descriptografia de um arquivo usando o algoritmo RSA.
Algoritmo de força bruta para quebra da chave criptográfica e uma heurística que permita
quebrar chaves um pouco maiores que o algoritmo de força bruta (e.g., Pollard-Rho).
• Geração das chaves pública e privada, principalmente a verificação de primalidade de um número;
• Algoritmo de Euclides Estendido;
• Função para criptografar e descriptografar dados de um arquivo;
• Algoritmo de força bruta para a fatoração da chave pública nos números primos que a geraram;
• Heurística para fatoração de números primos.
Fornecer gráficos com os tempos de execução da geração das chaves e dos dois procedimentos de fatoração
para inteiros com 𝑛 bits.
